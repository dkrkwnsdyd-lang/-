# 레퍼런스 인사이트 (샤오홍슈) — 크롬·파이어폭스 확장

샤오홍슈(xiaohongshu.com) 피드와 검색 결과에서 게시물마다 **성과배수·등급 배지**를 붙이고,
오른쪽 **분석 패널**에서 정렬·필터·CSV 내보내기를 합니다. 마음에 드는 글은 **레퍼런스로 저장**해 두었다가
팝업에서 한꺼번에 CSV로 받습니다. 모든 계산과 저장은 브라우저 안에서만 하고, 외부 서버로 보내지 않습니다.

## 지표

| 지표 | 공식 |
|---|---|
| 성과배수 | 좋아요 ÷ 지금 보고 있는 목록의 좋아요 **중앙값** |
| 반응점수 (0~100) | 성과배수 60점(20배 만점, 로그 눈금) + 저장률 25점(저장/좋아요 50% 만점) + 댓글률 15점(댓글/좋아요 10% 만점). 모르는 항목은 절반 점수 |
| 시간당 좋아요 | 좋아요 ÷ 올린 뒤 지난 시간 (게시 시각을 알 때만, CSV에 포함) |

등급은 **배수 또는 점수** 중 하나만 넘으면 됩니다(기본값: 폭발 10배·85점, 강력 5배·65점, 우수 3배·45점, 보통 1배·20점, 나머지 약함).
그래서 배수가 1 미만이어도 저장률이 높으면 "보통"이 될 수 있습니다. 기준은 팝업에서 바꿀 수 있습니다.

샤오홍슈는 남의 게시물 조회수를 공개하지 않아 **좋아요를 기준**으로 계산합니다.

## 설치

### 크롬 (또는 엣지·웨일)
1. 이 `extension` 폴더를 PC에 받습니다 (또는 `reference-insight.zip` 을 풀기).
2. 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택.

### 파이어폭스 (140 이상)
- 시험용: 주소창에 `about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드** → `manifest.json` 선택. 브라우저를 끄면 사라집니다.
- 계속 쓰려면: [addons.mozilla.org 개발자 허브](https://addons.mozilla.org/developers/)에서 **비공개(unlisted) 서명**을 받은 `.xpi` 를 설치합니다.

## 쓰는 법
- 샤오홍슈에서 검색하거나 피드를 스크롤하면 카드 오른쪽 위에 배지가 붙고, 화면 오른쪽에 패널이 뜹니다.
- 패널: 노트 수 · 중앙값 · 평균 · 최고 배수, 등급별 필터, 정렬(배수·점수·좋아요·저장·댓글), **CSV 내보내기**(지금 목록).
- 배지의 **레퍼런스 저장** → 툴바 아이콘(팝업)에서 모아 보고 CSV로 받기. 저장하는 건 링크·제목·숫자뿐입니다.

## shortsmaker로 보내기
팝업의 **shortsmaker로 보내기**에서 서버 주소(기본 `http://127.0.0.1:8000`)와, 암호를 걸어 둔 경우 접속 암호를 넣고
**저장한 레퍼런스 보내기**를 누릅니다. shortsmaker의 `/trends` 화면(스튜디오 상단 "트렌드 레퍼런스")에서 모아 볼 수 있습니다.
- PC(127.0.0.1) 외의 주소(같은 와이파이의 PC IP, Tailscale 주소 등)는 처음 보낼 때 브라우저가 접속 권한을 묻습니다.
- 접속 암호는 이 브라우저의 확장 저장소에만 저장됩니다.
- shortsmaker 쪽에 `/api/v2/trend-refs` 가 있는 버전이 필요합니다 (없으면 "업데이트해 주세요" 안내가 뜹니다).

## 데이터를 얻는 방법
- `src/inject.js`: 샤오홍슈가 **이미 받아 온** 응답(`/api/sns/...`)과 초기 상태(`__INITIAL_STATE__`)에서 게시물 숫자만 읽습니다. 새 요청을 보내지 않습니다.
- `src/content.js`: 위 데이터가 없으면 카드에 보이는 글자(예: `1.2万`)를 읽습니다.

## 확인 상태와 한계
- **실제 샤오홍슈에서는 아직 시험하지 못했습니다.** 개발 환경에서 사이트 접속이 막혀, 실제 구조를 흉내 낸 가짜 페이지(`test/mock-search.html`)로만 확인했습니다. 샤오홍슈의 응답 형식이나 화면 구조가 다르면 배지가 일부 안 붙을 수 있습니다.
- 크롬: 가짜 페이지에서 배지 22개, 패널 통계, 저장 → 팝업 → 실제 shortsmaker 서버로 보내기까지 자동 테스트 통과.
- 파이어폭스: `web-ext lint` 오류·경고 0개. 실제 파이어폭스 실행은 아직 안 해 봤습니다.
- 휴대폰 앱에서는 동작하지 않습니다(브라우저 확장이므로).
